## 🏛️ 1. Архитектура и Структура Репозиториев (Dual-Repo)

Проект состоит из двух взаимосвязанных репозиториев:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        HERMES ECOSYSTEM SETUP                          │
├───────────────────────────────────┬────────────────────────────────────┤
│  🎨 FRONTEND (Project Fenrir)      │  ⚙️ BACKEND (Hermes Core)          │
│  Путь: a:\project_Fenrir          │  Путь: A:\project_Hermes\...       │
│  Стек: React 18, Vite 5, TS,      │  Стек: Node.js, Express, Lowdb     │
│        Tailwind CSS, Lucide Icons │        JWT, Bcrypt, Multer/FS      │
│  Dev Server: http://localhost:5173 │  API & Static: http://localhost:3000│
└───────────────────────────────────┴────────────────────────────────────┘
```

### 🔄 Конвейер Сборки и Деплоя (Build Pipeline)
При внесении изменений во фронтенд:
1. Сборка продакшн-бандла в `a:\project_Fenrir`: `npm run build` (результат в `dist/`).
2. Копирование бандла в каталог раздачи бэкенда:  
   `Copy-Item -Path 'a:\project_Fenrir\dist\*' -Destination 'A:\project_Hermes\Hermes\college-ecosystem\college-ecosystem\public' -Recurse -Force`
3. Бэкенд Express мгновенно начинает раздавать обновленный интерфейс на `http://localhost:3000/`.

## 🎮 5. Логика Ключевых Механик

### А. Дейлики (Daily Streak Protocol)
* **Календарь недели:** Понедельник (`ISO 1`) — Воскресенье (`ISO 7`).
* **Награды:** Растут от `+100 XP / +10 ⟠` в ПН до `+700 XP / +70 ⟠` в ВС.
* **Строгое правило прерывания:** Если в день $D$ студент не забрал награды за предыдущие дни недели ($< D$), стрик помечается как `isBroken = true`, и все оставшиеся награды недели блокируются до наступления следующего календарного понедельника.
* **Сброс:** При смене понедельника (`weekStart != currentMonday`) стрик полностью обнуляется.

### Б. Неоновые Стили и Цветовая Тема
* Все купленные стили добавляются в массив пользователя `user.unlockedColors`.
* При нажатии «ПРИМЕНИТЬ» меняется CSS-переменная `--color-accent` на уровне `:root`, преображая все свечения, кнопки, бейджи и рамки.
* Сохраняется в `localStorage('hermes_accent')` и синхронизируется с профилем.

### В. Кибер-Питомец Hermes Drone
* Живой векторный аватар в `CyberPetAvatar`.
* Кастомизируется через слоты: `hat` (визоры, рожки, короны), `outfit` (броня), `boots` (маг-ботинки) и `color` (неоновый корпус).
* Реагирует на поглаживание кликом, издавая кибер-реплики и генерируя сердечки.
