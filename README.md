# HERMES // COLLEGE ECOSYSTEM PROTOCOL (v2.6)

Цифровая платформа колледжа: интерактивная лента кампуса, личные страницы операторов со стеной, защищённые каналы связи, система заданий и рейтингов, модульные кибер-питомцы и мерч-шоп.

---

## ⚡ Архитектура проекта

- **`backend/`** — серверная часть (Node.js, Express, аутентификация JWT, база данных, бэкапы, статика).
- **`frontend/`** — клиентское SPA-приложение (React, Vite, TypeScript, Tailwind CSS, Lucide Icons).

---

## 🚀 Быстрый старт

### 1. Требования
- Установленный [Node.js](https://nodejs.org) (v18, v20 или новее).

---

### 2. Запуск в режиме разработки (Dev)

#### Запуск Backend:
```bash
cd backend
npm install
npm start
```
Сервер будет доступен на: `http://localhost:3000`

#### Запуск Frontend (Vite HMR):
```bash
cd frontend
npm install
npm run dev
```
Фронтенд с горячей перезагрузкой откроется на: `http://localhost:5173`

---

### 3. Развёртывание в продакшн (Production)

Для работы в колледже фронтенд компилируется в статическую папку `backend/public`, после чего запускается только бэкенд на порту `3000`:

```bash
# 1. Сборка фронтенда
cd frontend
npm install
npm run build

# 2. Копирование сборки в бэкенд
# Windows (PowerShell):
Copy-Item -Path "dist\*" -Destination "..\backend\public\" -Recurse -Force

# 3. Запуск сервера
cd ..\backend
npm install
npm start
```

---

## 🔄 Непрерывная работа 24/7 (PM2)

Чтобы сервер в колледже не падал при закрытии терминала и автоматически запускался при перезагрузке ПК:

```bash
npm install -g pm2
cd backend
pm2 start server.js --name "hermes"
pm2 save
```

---

## 💾 Бэкапы и перенос данных

Вся база данных хранится в:
- `backend/data.json` — аккаунты, питомцы, чаты, посты, оценки и связи.
- `backend/public/uploads/` — загруженные фото, аватары и медиафайлы.

Автоматические бэкапы сохраняются в `backend/backups/`. Восстановление доступно в 1 клик через панель администратора во вкладке **БЭКАПЫ**.
